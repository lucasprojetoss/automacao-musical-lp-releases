# Atualizações — Automação Musical LP

Este repositório público hospeda **somente os arquivos de instalação e atualização assinados** do aplicativo Automação Musical LP para Windows.

O código-fonte e o desenvolvimento permanecem no repositório **privado** do proprietário. Este repositório não contém código-fonte, arquivos de áudio, históricos de veiculação, senhas ou chaves privadas.

## Como funciona

- Após os testes, uma nova versão numerada é publicada na seção **Releases**.
- O programa Windows compatível consulta o manifesto público `latest.json` e verifica criptograficamente a assinatura de cada pacote antes de instalar.
- A atualização é apresentada ao usuário e só pode ocorrer com a programação musical parada e mediante confirmação.
- A primeira instalação com atualizador ativo deverá vir de uma **release assinada**, não de uma compilação preliminar.

**Aviso:** enquanto não existir uma release oficial publicada e assinada, não há instaladores autoatualizáveis para baixar neste repositório.

[Ver versões publicadas](https://github.com/lucasprojetoss/automacao-musical-lp-releases/releases)
